# jeongjinkim.com

Personal academic website for JeongJin Kim, Assistant Professor of Psychology (I-O) at the University of Oklahoma.

## Structure

- `index.html` — landing page (static site)

## Local preview

Open `index.html` in a browser, or run a local server:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Intended for GitHub Pages with a custom domain (`jeongjinkim.com`). See repo Settings → Pages.
